I build small, sharp tools. Rust for the systems bits, TypeScript for the web, Python when it is the fastest path to done — currently an Aeronautical Engineering student.

### Building

- **[AgentPresence](https://github.com/Zenolitee/AgentPresence)** — a local Rust runtime that detects which AI coding agent (Codex, Pi, OpenCode) is active in your terminals and publishes it to Discord Rich Presence.
- **[playwright-scout](https://github.com/Zenolitee/playwright-scout)** — a deterministic Playwright QA scout that crawls a web app and generates the Playwright tests for it.
- **[asciify-ps](https://github.com/Zenolitee/asciify-ps)** — a Windows desktop GUI that turns images into colored ASCII art, with live preview.
